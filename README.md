# Project 1: Utility Usage Prediction Tool (No scikit-learn)

A beginner-friendly Python project that stores monthly utility usage in a CSV file and predicts the next month's usage using a simple linear regression calculation written with built-in Python.

## Features
- View monthly usage records
- Add a new month and usage value
- Update an existing month's usage
- Store data in a CSV file
- Predict next month's usage without scikit-learn
- Input validation and error handling

## Requirements
- Python 3
- No external packages are required

## Run in VS Code (Windows)
1. Extract this ZIP file.
2. Open the extracted `Project1_Utility_Usage_Prediction_No_SKlearn` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Check Python:
   ```cmd
   py --version
   ```
5. Run:
   ```cmd
   py main.py
   ```
   If `py` does not work but `python` does, use:
   ```cmd
   python main.py
   ```

No `pip install`, virtual environment, or scikit-learn installation is needed.

## Menu
1. View usage records
2. Add usage record
3. Update usage record
4. Predict next month's usage
5. Exit

Enter records in chronological order for a meaningful trend estimate. This is a small educational example, not a guaranteed utility forecast.
